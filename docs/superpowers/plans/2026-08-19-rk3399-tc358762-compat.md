# RK3399 TC358762 Compatibility Driver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Display an 800x480 desktop on the original Raspberry Pi 7-inch Touch Display by programming its TC358762 bridge after the RK3399 DSI host becomes operational.

**Architecture:** A project-specific I2C/DRM panel module replaces the incompatible built-in panel binding only for this overlay. It powers the ATTINY88 during panel prepare, performs Radxa's proven TC358762 generic-write sequence during panel enable, and exposes MCU PWM as a backlight while the existing module continues polling FT5426 touch.

**Tech Stack:** Linux DRM panel and MIPI DSI APIs, Linux I2C/backlight APIs, DKMS, Device Tree Compiler, POSIX shell, portable source-policy tests.

**Spec:** `docs/superpowers/specs/2026-08-19-rk3399-tc358762-compat-design.md`

## Global Constraints

- Target `radxa,rockpi4b-plus`, initially kernel `6.18.43-current-rockchip64`.
- Support only the original 800x480 display at panel I2C `0x45` and touch I2C `0x38`.
- Keep unused DSI0 disabled and route little VOP to DSI1.
- Preserve HDMI and `/etc/X11/xorg.conf.d/20-dfrobot-display.conf` unchanged.
- Program the TC358762 during panel `enable()`, never panel `prepare()`.
- Propagate every I2C and DSI initialization failure; never claim an enabled panel after failure.
- Package both modules as immutable DKMS version `0.2.0` with transactional migration from `0.1.1`.
- Preserve upstream and Radxa license/copyright notices and immutable source references.
- Do not reboot automatically; hardware validation remains pending until the user authorizes each reboot or power cycle.

- [ ] **Step 3: Implement panel data and transport helpers**

Create `src/panel_rockpi_rpi_touchscreen.c` with a project modification notice
and preserved upstream/Radxa notices. Define:

```c
struct rockpi_rpi_panel {
	struct i2c_client *i2c;
	struct drm_panel panel;
	struct mipi_dsi_device *dsi;
	struct backlight_device *backlight;
	bool prepared;
	bool enabled;
};

static int rockpi_mcu_read(struct rockpi_rpi_panel *ctx, u8 reg);
static int rockpi_mcu_write(struct rockpi_rpi_panel *ctx, u8 reg, u8 value);
static int rockpi_tc358762_write(struct rockpi_rpi_panel *ctx,
				 const u8 data[6]);
static int rockpi_tc358762_init(struct rockpi_rpi_panel *ctx);
```

Use SMBus byte-data operations for ATTINY88 registers `0x80` through `0x86`.
Use `mipi_dsi_generic_write()` for each six-byte Radxa register command and
stop at the first negative result. Copy the exact Radxa sequence documented by
the immutable source in `LICENSES/UPSTREAM.md`; do not silently continue after
a transfer error.

- [ ] **Step 4: Implement ordered DRM panel lifecycle**

Use the upstream fixed mode:

```c
static const struct drm_display_mode rockpi_panel_mode = {
	.clock = 25979,
	.hdisplay = 800, .hsync_start = 801, .hsync_end = 803, .htotal = 849,
	.vdisplay = 480, .vsync_start = 487, .vsync_end = 489, .vtotal = 510,
	.flags = DRM_MODE_FLAG_NHSYNC | DRM_MODE_FLAG_NVSYNC,
};
```

`prepare()` writes `REG_POWERON=1`, polls `REG_PORTB & 1` with a bounded sleep,
and sets `prepared` only on success. `enable()` requires prepared state, calls
`rockpi_tc358762_init()`, then writes `REG_PWM=255` and orientation bit 2 in
`REG_PORTA`, setting `enabled` only after every operation succeeds.
`disable()` writes PWM zero; `unprepare()` writes power zero. A shared stop
helper performs disable then unprepare and is used by remove and shutdown.

- [ ] **Step 5: Implement probe, DSI registration, and backlight**

Probe must read and validate `REG_ID == 0xc3` before panel registration. Locate
the remote DSI host from the panel graph, register channel zero with
`mipi_dsi_device_register_full()`, set:

```c
dsi->lanes = 1;
dsi->format = MIPI_DSI_FMT_RGB888;
dsi->mode_flags = MIPI_DSI_MODE_VIDEO |
	MIPI_DSI_MODE_VIDEO_BURST | MIPI_DSI_MODE_LPM;
```

Attach DSI, register the DRM panel, and register a raw backlight with maximum
255 whose update callback writes `REG_PWM`. Unwind in reverse order after any
failure. Use compatible `rockpi,rpi-7inch-touchscreen-panel` and module license
`GPL v2`.
